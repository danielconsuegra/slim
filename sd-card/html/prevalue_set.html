Fijar "valor previo"

HAZ CLIC AQUÍ para ver la descripción de uso. Más información en la documentación: "Valor previo"

Fija el "valor previo" para las comprobaciones de consistencia y para sustituir NaN

"Valor previo" es un nombre algo engañoso: normalmente es el último valor válido, pero no siempre el de la ronda anterior. El resultado de una nueva ronda, si es válido, pasa a ser el nuevo "valor previo". Si el resultado no sirve, el "valor previo" no se actualiza. Si está activado en la configuración, el "valor previo" se usa en la ronda siguiente para comprobar cambios negativos, cambios demasiado altos (MaxRateValue / MaxRateType) y para la opción "Check Digit Increase Consistency" (parámetro de configuración, solo para modelos dig-class11).

El campo para el nuevo "valor previo" viene relleno con el "valor bruto" actual porque es el caso más habitual. Aun así, puedes fijar cualquier otro valor positivo como nuevo "valor previo".
