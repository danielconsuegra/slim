Configuración

HAZ CLIC AQUÍ para ver la descripción de uso. Más información en la documentación: Parámetro

Esta página muestra todos los parámetros de configuración disponibles del dispositivo.
La descripción de cada parámetro se muestra al pasar el ratón por encima o al hacer clic en el icono.

La página se abre con la vista por defecto, suficiente para las tareas de configuración habituales. Al activar "Mostrar parámetros avanzados" se añaden a la lista algunos parámetros avanzados (con fondo rojo claro). Además, aparece arriba el botón "Editar archivo "Config.ini"" para editar manualmente el archivo de configuración (config.ini). Esta función solo debería usarse en casos especiales.

Las secciones (funcionalidad completa) o los parámetros con casilla se pueden activar o desactivar. Desactivar una sección completa desactiva esa funcionalidad. Si solo se desactiva un parámetro de una sección, se usa su valor por defecto interno.

No olvides guardar los cambios con el botón "Guardar configuración" al final de esta página.
