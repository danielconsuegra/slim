Paso 1 / 7: Ajustar el enfoque y comprobar el flash

Primero tienes que encontrar una buena posición de montaje y quizá ajustar el enfoque de la lente para obtener una imagen nítida. Esta transmisión en vivo con el flash encendido puede ayudarte. Hay más detalles sobre cómo ajustar la lente aquí: Ajuste del enfoque
Además, comprueba que el flash no cree reflejos molestos en las zonas relevantes para el procesamiento. Además del LED flash interno, también puedes conectar LEDs externos para tener más posibilidades de conseguir una buena iluminación. Lee la documentación si quieres usar LEDs externos: Instalación de LEDs externos

NOTA: en este paso la intensidad del flash está en el valor por defecto (50 %) para la comprobación inicial y se puede cambiar en el siguiente paso. Después puedes volver a este paso para probar con la nueva intensidad.
La transmisión en vivo también se puede abrir en cualquier momento desde la interfaz web normal, una vez terminado el modo de configuración.
