Bienvenido a la configuración de SLIM

Es la primera vez que inicias el dispositivo tras la instalación inicial. Se te ha dirigido automáticamente al procedimiento de configuración inicial. Con este procedimiento se realiza la configuración básica del dispositivo en siete pasos. Al completarlos, el modo de configuración termina y el dispositivo se reinicia automáticamente en la interfaz web normal.
Nota: todos los ajustes de la configuración inicial también están disponibles en la interfaz web normal. Consulta la documentación: Procedimiento de configuración inicial para más explicaciones.

Puedes avanzar y retroceder durante la configuración con los botones "Siguiente paso" y "Paso anterior".
Con el botón "Cancelar configuración" se omite la configuración y se muestra la pantalla de cancelación.
Para reiniciar el proceso de configuración, pulsa el botón "Reiniciar configuración".

Este es un resumen de los siete pasos:

  1. Ajustar el enfoque de la lente y comprobar los reflejos del flash.
    Asegúrate de que la lente de la cámara esté bien enfocada al objeto y de que el flash no produzca reflejos que distorsionen la imagen.

  2. Crear la imagen de referencia.
    Es la base para referenciar posiciones e identificar los dígitos y contadores.

  3. Definir dos marcas de alineación únicas.
    Se usan para alinear la orientación de las fotos de la cámara antes de procesarlas

  4. Definir las ROIs de los dígitos.
    Se usarán para digitalizar la parte de dígitos de tu contador.
    NOTA: si tu contador no tiene dígitos, puedes saltar este paso.

  5. Definir las ROIs de los contadores analógicos.
    Se usarán para digitalizar la parte analógica de tu contador.
    NOTA: si tu contador no tiene contadores analógicos, puedes saltar este paso.

  6. Configuración adicional: Lista de todos los parámetros
    Aquí puedes hacer más ajustes del dispositivo.
    NOTA: esto también se puede hacer después desde la interfaz web normal, p. ej. para configurar un servicio de publicación como MQTT

  7. Finalizar configuración: Terminar/cancelar el modo de configuración
    En el paso final hay que terminar correctamente el modo de configuración pulsando el botón de esa página.
    NOTA: esto es importante; de lo contrario, el modo de configuración vuelve a aparecer tras reiniciar.

Ten paciencia al cambiar de paso. ¡El dispositivo tarda un poco en cargar toda la información necesaria!

Si necesitas ayuda, consulta la documentación o las páginas de discusión .
