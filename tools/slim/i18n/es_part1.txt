162|La imagen de referencia es la imagen base sobre la que se definen las marcas de alineación, las ROIs de dígitos y las ROIs analógicas.
163|Al principio se muestra la imagen de referencia guardada. Si empiezas desde cero, se muestra una imagen por defecto de ejemplo. Usa el botón

168|Para un procesamiento fiable es obligatorio que las ROIs de dígitos estén alineadas en horizontal. El ángulo resultante se usa para pre-rotar la imagen antes del algoritmo de alineación, que solo compensa desviaciones pequeñas (ver el siguiente paso, Marcas de alineación). 406|Fija el "valor previo" para las comprobaciones de consistencia y para sustituir NaN
407|"Valor previo" es un nombre algo engañoso: normalmente es el último valor válido, pero no siempre el de la ronda anterior. El resultado de una nueva ronda, si es válido, pasa a ser el nuevo "valor previo". Si el resultado no sirve, el "valor previo" no se actualiza. Si está activado en la configuración, el "valor previo" se usa en la ronda siguiente para comprobar cambios negativos, cambios demasiado altos (MaxRateValue / MaxRateType) y para la opción "Check Digit Increase Consistency" (parámetro de configuración, solo para modelos dig-class11).
408|El campo para el nuevo "valor previo" viene relleno con el "valor bruto" actual porque es el caso más habitual. Aun así, puedes fijar cualquier otro valor positivo como nuevo "valor previo".
